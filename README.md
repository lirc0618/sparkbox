# Sparkbox · 个人收藏激活系统

Sparkbox 不是一个更大的收藏夹，而是一个让旧收藏重新出现、进入项目并最终转化为行动的个人系统。

## 已实现

- 收件箱：支持 URL / 纯文本快速收藏，URL 立即落库，提取不可用时明确显示人工补充提示。
- 批量导入：每行一条链接或文字，单次最多 200 条；重复链接自动跳过，整批一次性写入。
- 资料库：全部收藏、七阶段状态、跨标题/摘要/备注/正文/标签/来源/项目搜索与状态筛选。
- 项目：项目创建、编辑、删除；一条收藏可关联多个项目。
- 今日回顾：同日稳定选择最多 1–5 条，覆盖活跃项目、未打开旧收藏、待处理内容、长期参考和新收件箱。
- 反馈动作：立即查看、标记已使用、记录使用结果、加入项目、稍后提醒、跳过、不再推荐。
- 收藏 CRUD：新增、编辑、删除、归档、状态管理与详情页。
- 本地优先：未登录时业务数据写入浏览器 `localStorage`，刷新后保留。
- Eazo 云同步：支持邮箱登录、PostgreSQL 整库备份、对象级同步、冲突检测和同步健康检查。
- DeepSeek AI 整理：配置官方 API Key 后，可生成摘要、价值、下一步、标签、状态和项目建议。
- 14 天验证：排除内置示例，跟踪真实收藏数、活跃天数、已回顾内容和旧收藏激活结果。
- 数据安全：链接规范化与重复检测、JSON 全量导出与校验恢复、损坏原始数据保护、删除二次确认。
- 响应式界面：桌面左侧导航；手机底部导航。

## 本地运行

需要 Node.js 18 或更高版本。首次运行先安装依赖：

```bash
npm ci
npm start
```

然后打开：<http://localhost:3000>

开发和预览命令目前与正式启动相同：

```bash
npm run dev
# 或
npm run preview
```

测试与语法检查：

```bash
npm test
npm run check
```

## 核心闭环

```text
快速收藏
→ 收件箱补充标题 / 摘要 / 标签
→ 修改状态并关联项目
→ 今日回顾按规则重新出现
→ 查看、稍后、不再推荐或标记已使用
→ 记录实际使用结果
→ 在 14 天验证面板判断系统是否值得继续扩展
```

## 数据说明

- 存储键：`sparkbox.personal.v1`
- 数据范围：收藏、项目、回顾选择、回顾行为与个人设置。
- 示例数据：首次打开时写入 6 条收藏和 2 个项目；可在“数据与设置”中恢复。
- 备份：在“数据与设置”中可导出完整 JSON，也可选择备份文件恢复；只有完整校验通过后才会替换现有数据。
- 异常恢复：如果旧的本地数据无法解析，应用会先保留原始内容并提供恢复文件下载，不会静默丢弃。
- 验证建议：先导入约 30 条自己的真实收藏，再打开“14 天验证”开始周期；每天处理少量今日卡片并记录实际结果。
- 云同步：登录 Eazo 且配置 `DATABASE_URL` 后，可将本地状态首次迁移到 PostgreSQL；未配置或未登录时继续使用本地模式。

当前版本不会自动抓取网页正文，也不会伪造摘要。URL 会先安全保存，再提示人工补充；DeepSeek 只处理用户已经提供的文字。DeepSeek V4 是纯文本模型，截图不会上传，请先复制或转写可见文字。

## 可选的云端配置

复制 `.env.example` 为 `.env`，至少配置：

```dotenv
DATABASE_URL=postgresql://user:password@host:5432/database
EAZO_PRIVATE_KEY=replace-with-your-eazo-private-key
DEEPSEEK_API_KEY=replace-with-your-deepseek-api-key
DEEPSEEK_MODEL=deepseek-v4-flash
```

`DATABASE_URL` 和 Eazo 私钥只用于云同步及登录；`DEEPSEEK_API_KEY` 只在服务端调用 DeepSeek，不会发送到浏览器。默认使用 `deepseek-v4-flash`，需要更强效果时可改成 `deepseek-v4-pro`。不要提交 `.env`。如果只使用本地模式且不使用 AI，不需要创建 `.env`。

## 项目结构

```text
index.html          页面入口
styles.css          响应式视觉系统
src/app.js          路由、页面与交互
src/domain.js       收藏规则、搜索与每日回顾算法
src/store.js        本地持久化与 CRUD

server.mjs          静态服务器、Eazo 鉴权、PostgreSQL 同步与 DeepSeek API

```

## 部署

仅使用本地模式时，前端资源可以部署到静态站点。需要登录、云同步或 AI 时，必须部署 `server.mjs`，安装生产依赖，并注入 `.env.example` 中对应的服务端环境变量。

迁移到 Eazo 的数据表、实施顺序和可直接粘贴的提示词见 [EAZO_DEPLOYMENT.md](./EAZO_DEPLOYMENT.md)。

## 当前边界

- 未登录时仍是单用户、单浏览器存储；清理站点数据会删除本地内容，请定期导出 JSON。
- 云端当前保存整份状态 JSON，并维护对象级同步账本；尚未拆分为规范化业务表。
- 没有自动网页抓取、图片识别、公开注册、团队或支付。
- 浏览器端 Eazo SDK 目前从 `esm.sh` 动态加载，首次登录检查需要联网。
